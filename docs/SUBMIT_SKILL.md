# Submit Your Skill

Have a tested workflow other artists could use? Send it to **info@3dground.net** for review. Submission does not guarantee inclusion in Max Ultra MCP.

1. Test the skill and check its result.
2. Remove private paths, customer data, credentials, and identifying information from text and images.
3. Create a ZIP with **SKILL.md** at its root or inside one enclosing folder, plus any required references and images. You can test this ZIP with **Skills > Custom > Import ZIP**.
4. Attach the ZIP and complete the template below. Include the permission statement only if you can confirm it.

[Open your email application](mailto:info@3dground.net?subject=Max%20Ultra%20MCP%20skill%20submission)

This opens a draft; nothing is sent automatically.

## Mail template

```text
To: info@3dground.net
Subject: Max Ultra MCP skill submission - [Skill name]

Skill name: [Name]
Author / display name: [Your credit]
Credit link (optional): [Website or profile]
Purpose: [Task and when to use the skill]
Tested versions: [3ds Max, Max Ultra MCP, AI client, renderer/plugins]
Required setup: [Inputs, assets, selection, units or permissions]
How to reproduce: [Starting state and example request]
Expected result and checks: [Outcome and how you verified it]
Known limitations: [Unsupported or untested cases]
Attachment: [Skill ZIP and sanitized examples, if useful]

Permission:
I created this material or have permission to submit it.
I permit the Max Ultra MCP author to review, adapt and distribute
this contribution as part of Max Ultra MCP with attribution
to the display name above.
Third-party material and terms: [List any, or write None]
```
